# START GROUP Z GROWTH

Dashboard e pipeline de dados Amazon Vendor (SP-API) do Grupo Start.

Este repositório é o sucessor do [`STARTZ`](https://github.com/Grupo-start-onset/STARTZ):
mesmo dashboard, mesma estrutura de dados — mas com a coleta de dados da
Amazon rodando via scripts Python (`scripts/`), sem depender do Google
Colab. Veja `scripts/README.md` para como configurar e rodar.

O `STARTZ` continua no ar normalmente enquanto esta nova pipeline é
validada; nada aqui afeta o repositório antigo.
